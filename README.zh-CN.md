# Hengliyuan Sweetener Blend Cost Calculator

Estimate blend cost, loss, bulk cartons, editable USD comparison and reference sweetness without uploading a formula.

英文独立版。仅包含本工具；[公司官网](https://heng-li-yuan.com/) · [演示](https://briton2008.github.io/hengliyuan-sweetener-blend-cost-calculator/) · [完整英文说明](README.md)。

Node.js 22.12+；运行 `npm ci --ignore-scripts`、`npm test`、`npm run check:release`、`npm run build`。浏览器检查先 `npx playwright install chromium`，再 `npm run test:browser`。

计算结果为参考，业务限制、数据范围与第三方来源见英文说明；未确认项保持待确认。MIT代码不授权冒用公司名称、品牌或公司模板开具正式文件，见TRADEMARKS.md。
